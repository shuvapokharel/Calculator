# Calculator

A simple calculator made with HTML, CSS, and JavaScript.

## Live Demo

[Calculator](https://calculator-sigma-tan.vercel.app/)

## What it can do

- Add
- Subtract
- Multiply
- Divide
- Clear the calculation

## How to use

1. Clone this repository.
2. Open `index.html` in your browser.
3. Start calculating.
